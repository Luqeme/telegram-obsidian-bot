# 🗺 Карта базы

Точка входа в хранилище: что не разобрано, какие есть проекты и темы, где что лежит.
Статистика, задачи и деньги — в [[Dashboard]].

## 📥 Инбокс

```dataviewjs
const pages = dv.pages('"00_Inbox"').sort((p) => p.created, "asc")
const today = dv.date("today").startOf("day")

if (!pages.length) {
  dv.paragraph("Пусто — инбокс разобран.")
} else {
  dv.table(
    ["Заметка", "Категория", "Дней"],
    pages.map((p) => {
      const created = p.created && typeof p.created.toFormat === "function" ? p.created : null
      const days = created ? Math.round(today.diff(created.startOf("day"), "days").days) : ""
      return [dv.fileLink(p.file.path, false, p.title ?? p.file.name), p.category ?? "", days]
    })
  )
}
```

## 🚀 Проекты

```dataviewjs
const upName = (p) => {
  const up = Array.isArray(p.up) ? p.up[0] : p.up
  if (!up) return ""
  if (typeof up === "string") return up.replace(/^\[\[|\]\]$/g, "").split("|")[0]
  return up.path ? up.path.replace(/\.md$/, "") : ""
}

const hubs = dv
  .pages()
  .where((p) => p.type === "project")
  .sort((p) => p.file.name, "asc")

if (!hubs.length) {
  dv.paragraph("Хабов пока нет.")
} else {
  for (const hub of hubs) {
    const children = dv
      .pages()
      .where((p) => upName(p) === hub.file.path.replace(/\.md$/, ""))
      .sort((p) => p.created, "asc")
    dv.header(4, dv.fileLink(hub.file.path, false, hub.title ?? hub.file.name))
    if (children.length) {
      dv.list(children.map((p) => dv.fileLink(p.file.path, false, p.title ?? p.file.name)))
    } else {
      dv.paragraph("Заметок пока нет.")
    }
  }
}
```

## 🧭 Темы

```dataviewjs
const skip = ["Карта", "Dashboard", "README"]
const notes = dv.pages().where((p) => !skip.includes(p.file.name))

const counts = new Map()
for (const p of notes) {
  for (const tag of p.file.tags ?? []) counts.set(tag, (counts.get(tag) ?? 0) + 1)
}

const top = Array.from(counts.entries())
  .sort((a, b) => b[1] - a[1])
  .slice(0, 8)

if (!top.length) {
  dv.paragraph("Тегов пока нет.")
} else {
  for (const [tag, count] of top) {
    dv.header(4, `${tag} · ${count}`)
    dv.list(
      notes
        .filter((p) => (p.file.tags ?? []).includes(tag))
        .map((p) => dv.fileLink(p.file.path, false, p.title ?? p.file.name))
    )
  }
}
```

## 🧊 Без связей

```dataviewjs
const islands = dv
  .pages()
  .where((p) => !["Карта", "Dashboard", "README"].includes(p.file.name))
  .where((p) => p.type !== "project")
  .where((p) => (p.file.inlinks ?? []).length === 0 && (p.file.outlinks ?? []).length === 0)

if (islands.length) {
  dv.paragraph("Эти заметки ни с чем не связаны — кандидаты на связь или на удаление.")
  dv.list(islands.map((p) => dv.fileLink(p.file.path, false, p.title ?? p.file.name)))
} else {
  dv.paragraph("Связано всё — островов нет.")
}
```

## 🧭 Как читать граф

- `Ctrl+G` — общий граф: кружки — заметки, линии — ссылки.
- Открой заметку → правый сайдбар → **Backlinks**: кто на неё ссылается.
- Правый клик по заметке → **Open local graph**: только её соседи.
- Размер кружка растёт от числа связей; хабы проектов — самые крупные узлы.

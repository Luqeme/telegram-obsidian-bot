# Шаблон хранилища Obsidian

Готовая структура папок и дашборд для базы, которую наполняет бот.

## Как использовать

1. Склонируй репозиторий с заметками (или открой уже существующий клон).
2. Скопируй содержимое этой папки в **корень** хранилища:

```bash
cp -r examples/vault/* /path/to/your-vault/
```

3. Открой папку в Obsidian как хранилище.
4. Settings → Community plugins → Browse → **Dataview** → Install → Enable.
5. Так же установи **Charts** — он рисует графики.
6. Открой `Dashboard.md`.

## Что внутри

| Папка | Назначение |
|---|---|
| `00_Inbox` | сюда пишет бот. Очередь на разбор, а не хранилище |
| `10_Notes` | постоянные заметки: идеи, мысли, наблюдения |
| `20_Projects` | задачи, материалы и файлы-хабы проектов |
| `30_Дом` | текущие бытовые дела: общий чек-лист, куда бот дописывает задачи |
| `90_Archive` | отработанное, но нужное для истории |
| `99_Templates` | шаблон хаба проекта |

`Dashboard.md` — Dataview-запросы: инбокс, открытые задачи, залежавшиеся заметки, разбивка по категориям и тегам.

`Карта.md` — домашняя страница: инбокс, проекты, темы, последние заметки и заметки без связей.

## Проекты и граф

Проект — файл-хаб в `20_Projects` с полем `type: project`. Заметка привязывается к нему одной строкой:

```yaml
up: "[[Dashboard]]"
```

Хаб сам собирает свои заметки и открытые задачи; в графе Obsidian появляется иерархия «хаб → заметки». Скопируй `99_Templates/Проект.md`, замени `type: project-template` на `type: project` — и новый хаб готов.

## Бытовые дела

`30_Дом/Бытовые дела.md` — общий чек-лист. Бот сам дописывает туда бытовые задачи («купить молоко», «заехать в аптеку», «забрать посылку»), а не создаёт отдельные заметки. Задачи видны в `/today`, на дашборде и на карте. Отмечать выполненные можно прямо в Obsidian.

## Правило разбора

Одно действие: **переноси файл из `00_Inbox` в нужную папку**. Всё.

Поле `status:` в шапке заметки бот ставит для себя, менять его не нужно — инбокс определяется папкой, а не полем.

Раз в неделю инбокс должен быть пуст. Дашборд сам подсветит заметки старше семи дней.

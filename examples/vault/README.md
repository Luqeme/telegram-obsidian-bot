# Шаблон хранилища Obsidian

Готовая структура папок и дашборд для базы, которую наполняет бот.

## Как использовать

1. Склонируй репозиторий с заметками (или открой уже существующий клон).
2. Скопируй содержимое этой папки в **корень** хранилища:

```bash
cp -r examples/vault/* /path/to/your-vault/
```

3. Открой папку в Obsidian как хранилище.
4. Settings → Community plugins → Browse → **Dataview** → Install → Enable.
5. Открой `Dashboard.md`.

## Что внутри

| Папка | Назначение |
|---|---|
| `00_Inbox` | сюда пишет бот. Очередь на разбор, а не хранилище |
| `10_Notes` | постоянные заметки: идеи, мысли, наблюдения |
| `20_Projects` | задачи и материалы по активным делам |
| `90_Archive` | отработанное, но нужное для истории |

`Dashboard.md` — Dataview-запросы: инбокс, открытые задачи, залежавшиеся заметки, разбивка по категориям и тегам.

## Правило разбора

Одно действие: **переноси файл из `00_Inbox` в нужную папку**. Всё.

Поле `status:` в шапке заметки бот ставит для себя, менять его не нужно — инбокс определяется папкой, а не полем.

Раз в неделю инбокс должен быть пуст. Дашборд сам подсветит заметки старше семи дней.

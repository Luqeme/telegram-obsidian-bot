# Название проекта

Одно предложение: что это за проект и зачем он.

> Это шаблон. При создании проекта:
> 1. скопируй файл в `20_Projects/` под именем проекта;
> 2. замени `type: project-template` на `type: project`;
> 3. заполни название и описание.

## Заметки

```dataviewjs
const upName = (p) => {
  const up = Array.isArray(p.up) ? p.up[0] : p.up
  if (!up) return ""
  if (typeof up === "string") return up.replace(/^\[\[|\]\]$/g, "").split("|")[0]
  return up.path ? up.path.replace(/\.md$/, "") : ""
}

const hub = dv.current().file.path.replace(/\.md$/, "")
const notes = dv
  .pages()
  .where((p) => upName(p) === hub)
  .sort((p) => p.created, "asc")

if (notes.length) {
  dv.list(notes.map((p) => dv.fileLink(p.file.path, false, p.title ?? p.file.name)))
} else {
  dv.paragraph("Заметок пока нет.")
}
```

## Открытые задачи

```dataviewjs
const upName = (p) => {
  const up = Array.isArray(p.up) ? p.up[0] : p.up
  if (!up) return ""
  if (typeof up === "string") return up.replace(/^\[\[|\]\]$/g, "").split("|")[0]
  return up.path ? up.path.replace(/\.md$/, "") : ""
}

const hub = dv.current().file.path.replace(/\.md$/, "")
const tasks = []
for (const p of dv.pages().where((p) => upName(p) === hub)) {
  for (const task of p.file.tasks ?? []) {
    if (!task.completed) tasks.push(task)
  }
}

if (tasks.length) {
  dv.taskList(tasks, false)
} else {
  dv.paragraph("Открытых задач нет.")
}
```

## Как пополнять

При разборе заметки добавь в её frontmatter:

```yaml
up: "[[Название проекта]]"
```

Заметка появится в списке выше, а связь — в графе.

# Дашборд «Обсидиан»

Read-only Mini App: один экран с днём, деньгами и задачами. Открывается из бота
кнопкой «📊 Дашборд», живёт на российском VPS (`dash.cloudfern.ru`).

## Как устроено

```
Telegram WebView → nginx (TLS) → uvicorn 127.0.0.1:8000 → GitHub API → vault
```

- `app.py` — FastAPI, статика и два эндпоинта;
- `auth.py` — проверка `initData` (HMAC-SHA256 токеном бота);
- `data.py` — сборка ответа из `services/`, кэш 30 секунд;
- `static/index.html` — весь фронт, без сборки и внешних библиотек.

Записи нет: эндпоинты только читают. Доступ — белый список `ALLOWED_TELEGRAM_USERS`,
чужая подпись получает 403, отсутствующая или просроченная — 401.

`initData` и цвета темы страница берёт из hash-фрагмента URL: официальный
`telegram-web-app.js` с `telegram.org` из России недоступен.

## Выкатка

```bash
python dashboard/deploy.py              # обновление
python dashboard/deploy.py --init-env   # первая установка: создать .env из локального
```

Нужен SSH-алиас `cloudfern` в `~/.ssh/config`. Скрипт собирает архив, ставит
зависимости, перезапускает `obsidian-dashboard` и проверяет `/healthz`.

**`.env` на сервере не перезаписывается.** Там лежит GitHub-токен только на
чтение, а в локальном `.env` — полный токен бота. Подмена вернула бы дашборду
права на запись в хранилище.

## Важное

- Часовой пояс берётся из `TIMEZONE` (`Asia/Yekaterinburg`), а не из системы.
- GitHub-токен дашборда: fine-grained, `Contents: Read-only`, один репозиторий.
- Токен бота нужен для проверки подписи; `GROQ_API_KEY` на сервере — заглушка.
- Данные отстают до 2 минут: TTL индекса 120 с плюс кэш дашборда 30 с.
